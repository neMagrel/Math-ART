# Checkpoints

Каждый checkpoint — самостоятельный запускаемый `.py`-файл с тем же teacher foundation, что и `01_start.py`, и ученическим кодом текущего уровня.

Последовательность:

1. `02_point.py` — точка в центре.
2. `03_circle.py` — одна движущаяся точка.
3. `04_lissajous.py` — формулы `a / b`.
4. `05_particles.py` — цикл и несколько фаз.
5. `06_final.py` — цвет, линии и неоновый след.

Recovery: открыть ближайший известный хороший файл → Run → продолжить занятие. Ничего копировать или восстанавливать через Git не нужно.
