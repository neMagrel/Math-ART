# Preflight перед занятием

Выполнить на каждом типе ученического компьютера заранее.

- [ ] IDE запускает ожидаемый Python 3.11+ или единую версию аудитории.
- [ ] `python -c "import pygame; print(pygame.version.ver)"` проходит.
- [ ] `python -c "from PIL import Image; print(Image.__version__)"` проходит либо GIF заранее объявлен недоступным.
- [ ] `python 00_demo.py` работает плавно.
- [ ] `python 01_start.py` открывает тёмное окно и закрывается по `Esc`/крестику.
- [ ] Все существующие `checkpoints/*.py` запускаются самостоятельно.
- [ ] Папка `output/` доступна для записи.
- [ ] `P` создаёт непустой `output/math_art_wallpaper.png`.
- [ ] При доступном Pillow: `G` → 3–5 секунд → `G` создаёт открываемый `output/math_art_animation.gif`.
- [ ] На слабом ПК проверены `04_lissajous.py` и `06_final.py`.
- [ ] Во время урока не нужны сеть, скачивание или установка.

При проблеме Pillow пропустить GIF: PNG остаётся обязательным и полностью рабочим результатом.
