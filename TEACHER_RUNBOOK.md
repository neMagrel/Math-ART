# Teacher Runbook

## Цель

За 60 минут ребёнок проходит путь «точка → движение → Лиссажу → частицы → неон», меняет результат под себя и обязательно сохраняет PNG. GIF остаётся бонусом.

## Граница ответственности

Teacher-owned foundation: imports, `pygame.init()`, окно, `Clock`, `FPS`, `dt`, `while running`, события, surfaces, fade, реализация `hsv_color()`, `previous_points` storage/reset, интерфейс, controls, output path, PNG/GIF и Pillow fallback.

Student-owned code: `x`, `y`, `pygame.draw.circle`, обновление `time_value`, `sin`/`cos`, `a`, `b`, радиусы, цикл `for`, `i`, `phase`, вызов `hsv_color`, подключение previous point, `pygame.draw.line`, обновление `previous_points` и свои значения параметров.

## Карта 60 минут

| Время | Шаг | Видимый результат | Recovery |
|---|---|---|---|
| 0–10 | Demo → цель → starter | У всех открыто тёмное окно | Проверенный проект или другой ПК |
| 10–16 | Точка | Белая точка | `checkpoints/02_point.py` |
| 16–23 | Движение | Точка движется по кругу | `checkpoints/03_circle.py` |
| 23–31 | Лиссажу | Сложный узор | `checkpoints/04_lissajous.py` — hard gate |
| 31–39 | Частицы | Несколько точек | `checkpoints/05_particles.py` |
| 39–45 | Неон | Цветные линии и след | `checkpoints/06_final.py` |
| 45–52 | Персонализация | Работы различаются | Не сокращать |
| 52–56 | Экспорт | PNG реально лежит в `output/` | GIF пропустить при проблеме |
| 56–60 | Галерея и итог | Ребёнок объясняет ядро | Новый код не добавлять |

## Recovery protocol

1. За 60–90 секунд сравнить только последние изменённые строки с кодом на проекторе.
2. Проверить отступ, скобки, двоеточие и имя переменной.
3. Если ошибка не найдена, открыть ближайший известный самостоятельный checkpoint.
4. Нажать Run и вернуть ребёнка к общему шагу.

Git для recovery детям не нужен.

## Контроль темпа

- К 31-й минуте у большинства должен быть Лиссажу. Иначе открыть `04_lissajous.py`.
- К 45-й минуте нужен финальный вид. Иначе открыть `06_final.py` и сохранить время на авторскую версию.
- Для медленной группы первыми сокращаются GIF, ручной набор части neon-логики и часть объяснения цикла.
- Персонализация и PNG не сокращаются.
- Быстрой группе можно предложить сравнить `a == b`, связать скорость цвета со `speed` или найти два разных удачных узора без добавления новой архитектуры.

## Проверенные пары для возврата к красивому узору

| Название | `a` | `b` |
|---|---:|---:|
| Classic | 3 | 4 |
| Star | 5 | 4 |
| Dense | 5 | 7 |
| Calm | 2 | 3 |
| Experiment | 7 | 8 |

Сначала ребёнок меняет `a`, `b`, `particle_count`, `speed`, `point_radius`, `radius_x` и `radius_y` в source как разработчик. Только затем он исследует те же параметры готовыми controls как пользователь.

## Финал

PNG — обязательный take-home. GIF — бонус при рабочем Pillow и достаточном времени. Установка анимированных обоев не входит в занятие.
