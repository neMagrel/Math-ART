# Math Art Generator

Небольшой проект на Python и Pygame для 60-минутного мастер-класса по генеративной графике.

Сейчас в репозитории зафиксирован полный преподавательский demo: `00_demo.py`.

## Быстрый запуск demo

```text
python -m pip install -r requirements.txt
python 00_demo.py
```

PNG и GIF сохраняются в папку `output/` рядом с файлами проекта.
