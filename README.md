# Math Art Generator

Classroom-ready проект для 60-минутного мастер-класса: от одной точки до собственной неоновой анимации на Python и Pygame.

## Файлы занятия

- `00_demo.py` — полный teacher demo для начала занятия.
- `01_start.py` — канонический starter: вся техническая основа готова, student zone ещё пустая.
- `checkpoints/` — самостоятельные версии каждого ученического шага.
- `output/` — единое место для сохранённых PNG и GIF.
- `TEACHER_RUNBOOK.md` — поминутное ведение занятия и recovery.
- `STUDENT_FLOW.md` — короткий маршрут ученика.
- `PRELIGHT.md` — проверка компьютеров до занятия.

## Зависимости

Рекомендуется Python 3.11+ или единая заранее проверенная версия аудитории.

```text
python -m pip install -r requirements.txt
python -c "import pygame; from PIL import Image; print('OK')"
```

Pygame обязателен. Pillow нужен только для бонусного GIF; PNG сохраняется через Pygame без Pillow. Во время занятия ничего устанавливать не нужно.

## Запуск

```text
python 00_demo.py
python 01_start.py
python checkpoints/06_final.py
```

Каждый checkpoint запускается отдельно. Независимо от текущей рабочей папки PNG и GIF попадают в project-level `output/`.

## Управление

- `←` / `→` — изменить `a`.
- `↑` / `↓` — изменить `b`.
- `W` / `S` — скорость.
- `+` / `-` — количество частиц.
- `Space` — случайные параметры.
- `R` — очистить след.
- `H` — показать или скрыть подсказку.
- `P` — сохранить обязательный PNG `output/math_art_wallpaper.png`.
- `G` — начать или закончить бонусную запись `output/math_art_animation.gif`.
- `Esc` — выход.

Сначала ребёнок меняет параметры в исходном коде как разработчик. Готовые клавиши используются после этого как второй уровень исследования.
